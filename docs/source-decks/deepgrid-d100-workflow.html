Architectural Rationale

Executes the hard real-time PX4 / ArduPilot flight loop out of zero-wait-state ECC SRAM. By strictly avoiding instruction and data caches, the core guarantees deterministic Worst-Case Execution Time (WCET) under aggressive drone attitude maneuvers.

Failure Mode Hardening

If electromagnetic interference (EMI) or power transients induce a bit-flip in Core A, the 2-cycle lockstep comparator asserts FAULTn within ≤2 cycles, halting corrupt PWM output and handing authority to the Failsafe Island.
